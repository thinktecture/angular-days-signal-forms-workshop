# Exercises

| Folder                        | Starting point (edit this)              | Solution route                 |
| ----------------------------- | --------------------------------------- | ------------------------------ |
| `01-template-to-signal-form/` | `src/app/components/template-form/`     | `/solutions/template-form`     |
| `02-reactive-to-signal-form/` | `src/app/components/reactive-form/`     | `/solutions/reactive-form`     |
| `03-conditional-validation/`  | `src/app/components/hotel-booking/`     | `/solutions/hotel-booking`     |
| `04-async-validation/`        | `src/app/components/async-validation/`  | `/solutions/async-validation`  |
| `05-signal-form-with-store/`  | `src/app/components/store-form/`        | `/solutions/store-form`        |
| `06-dynamic-json-form/`       | `src/app/components/dynamic-json-form/` | `/solutions/dynamic-json-form` |

Each folder contains a `README.md`, a `template/` copy of the starting point and the `solution/`.
The solutions are part of the build, so they always compile against the installed Angular version.

To restore a starting point:

```sh
git checkout -- src/app/components/<component>/
```

See `cheatsheet.md` for the API summary.
